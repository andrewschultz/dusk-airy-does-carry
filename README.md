# Dusk, Airy, Does Carry

Adventuron game/text adventure originally published October 30, 2025 as my third of three entries (*Go-Strange-Ghost Range* and *Chez Dark Shade Ark*) to EctoComp 2025 Petite Mort. It placed 13th of 32 entiries. They all share a certain mechanic. I wasn't planning on a third EctoComp entry, but the ideas piled up, and I had the time. It has ten rooms, all accessible after the initial puzzle, and twelve points. Each puzzle has a two-word solution, but some depend on others to move forward.

A compiled HTML version of the game is at [on itch.io](https://andrewschultz.itch.io/dusk-airy-does-carry). You sohuld be able to run from there, but if not, there is a downloadable HTML file.

The repository contains source code, a game map, a logic map and a walkthrough, all of which should be on the Itch page, too. The graphics subdirectory has, well, the graphics.

While the theme is a bit of a stretch for EctoComp (silliness over scariness,) I was in the mood to draw a few more silly graphics, so I did. And there IS an evil wight to defeat.

Oh, it also ends with a cliche (and starts with one.) But I hope it's a funny take on said cliche.

The project is stable with few changes expected.
